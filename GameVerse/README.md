# 🎮 GameVerse

GameVerse is a modern gaming discovery website built using HTML5 and CSS3.

The project focuses on creating a professional gaming UI without using JavaScript.

## 🚀 Features

- Responsive navigation bar
- Full-screen hero section
- Popular games section
- Game cards
- Hover effects
- Game categories
- Featured game section
- Top-rated games ranking
- Newsletter section
- Responsive footer
- Mobile responsive design
- CSS animations and transitions

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Variables
- Media Queries
- Font Awesome
- Google Fonts

## 📱 Responsive Design

GameVerse is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

## 🎯 Purpose

This project was created as a frontend practice project to demonstrate:

- HTML structure
- CSS styling
- Flexbox
- CSS Grid
- Responsive design
- Hover effects
- UI design
- Website layout
