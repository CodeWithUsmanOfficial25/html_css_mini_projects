# 🏨 LuxeStay

LuxeStay is a modern and responsive hotel landing page designed to showcase a luxury hotel experience.

## ✨ Features

- Responsive navigation bar
- Hero section
- Luxury hotel rooms
- Room cards
- Amenities section
- Pricing section
- Testimonials
- Contact section
- Responsive design for mobile, tablet and desktop
- Separate dashboard interface
- Modern bright color scheme
- Flexbox and CSS Grid layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
