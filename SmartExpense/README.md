# 💸 SmartExpense — Personal Finance Dashboard

A modern, multi-page **personal finance dashboard UI** built with **HTML5 and CSS3**. SmartExpense is designed as a frontend portfolio project for practicing page structure, reusable styling, responsive layouts, navigation, and dark glassmorphism-inspired UI design.

> **Project type:** Static frontend prototype  
> **Technologies:** HTML5 · CSS3  
> **Data:** Sample/demo content only

---

## ✨ Overview

SmartExpense brings common personal-finance screens together in one consistent interface. The layout uses a dark visual theme, translucent-looking panels, subtle borders, and purple/cyan accents to create a polished dashboard experience.

The project is intentionally built with **HTML and CSS only**. It demonstrates the visual structure of a finance app without connecting to a database or implementing real financial operations.

## 🎨 Design Highlights

- 🌑 **Dark dashboard theme** with purple and cyan accent colors.
- 🪟 **Glassmorphism-inspired UI** using layered panels, borders, and visual depth.
- 🧩 **Consistent multi-page layout** with shared sidebar navigation.
- 📱 **Responsive styling** for desktop, tablet, and mobile screen sizes.
- 📈 **CSS-based chart visuals** for dashboard and analytics presentation.
- 🖱️ **Navigation between pages** using regular HTML links.
- ♿ **Usability details**, including form labels and visible keyboard-focus styles.
- 🧼 **Reusable CSS styling** to keep the pages visually consistent.

## 🚀 Run the Project Locally

### Option 1: Open the HTML file

1. Download or clone this project.
2. Extract the ZIP file if you downloaded it.
3. Open the `SmartExpense` folder.
4. Open `index.html` in your browser.
5. Use the sidebar links to explore the other pages.

### Option 2: Use VS Code and Live Server

1. Open **Visual Studio Code**.
2. Select **File → Open Folder**.
3. Choose the extracted `SmartExpense` project folder.
4. If you have the **Live Server** extension installed, right-click `index.html`.
5. Select **Open with Live Server**.
6. Navigate through the dashboard using the sidebar.

## ⚠️ Scope and Limitations

SmartExpense is a **static UI prototype**, not a working financial management service.

- 💡 All financial amounts and transactions are sample content.
- 📝 Forms are visual layouts and do not save submitted information.
- 🔎 Search and filter controls are not connected to transaction data.
- 🔘 Preference controls do not persist settings.
- 📊 Charts are visual demonstrations and are not calculated from live data.
- 🔐 There is no authentication, database, or backend API.

These limitations are expected for an HTML/CSS-only learning project. **Do not enter real financial or personal information** into the demo forms.
